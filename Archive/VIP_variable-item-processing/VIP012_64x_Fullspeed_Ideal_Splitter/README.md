Split mixed boxes into single type boxes at 64x hopperspeed. Produces minimum partial boxes. Unlike [VIP003 32X and 64X Compact Ideal Splitter](https://discord.com/channels/1375556143186837695/1388318356377043076), this device has no item type switching downtime and can operate at fullspeed regardless of input variance. It uses 3wt loader, a dolphin-based item refresher, and built-in box yeeting.
## Features
- 9 x 17 x 37
- Zero downtime item-type switching; no slowdown while switching between item types
- 3wt box loaders
- No idle hopper minecarts
- Fully locked hopper in loaders
- Dolphin-based item refresher
- Cactus-based box yeeting box unloader
## Considerations
- Lag from entities scales quadratically with the amount of items input in a single batch.
- The dolphin-based item refresher may be slow in 26.1-26.3 due to Mojang's nerfing of dolphins.
## Notes
The design has been tested with approximately 30,000 boxes. Uses counter from [VIP003 32X and 64X Compact Ideal Splitter](https://discord.com/channels/1375556143186837695/1388318356377043076)
## Compatibility
1.21.6+ except 26.1-26.2
## Instructions
1. Put items (any item including boxes), into topmost water stream (by the birch fence gate).
