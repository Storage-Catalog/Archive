A device that assigns different item types to their own chests to recolor them.
## Features
- Recolors each box in 18 GT.
- Idle cartless: removes the hopper minecart when the device is not in use.
- Checks that all chests contain their contents before starting and shuts down if the chests are not reset while it is running.
- Has two separate outputs: the lower output is for dyes, and the top output is for boxes.
- Supports shulker boxes, including recoloring the same box; it outputs both dyes and boxes.
- If it runs out of dyes, it will not recolor the box and will continue working.
- Completely expandable and adjustable; slices can be configured to add or remove colors.
## Considerations
- Dry-fire proof: it will not scramble the encoder, but it will lose minecarts and clog the droppers at the end.
## Notes
Fully Hopperlocking is possible if you desire
## Compatibility
1.21 Crafters
