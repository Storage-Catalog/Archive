A noteblock-driven system that breaks a displayed box, leaves it for the player, and replaces it with a new empty box. It also allows the player to toss a box from their inventory (onto the pale carpet) to display the tossed box instead. The noteblock, displayed box, and toss input are aligned in the center of a hall.
## Features
- Toss Input
- TNT Proof
## Considerations
- Not possible to fit a readout for the bottom dropper
