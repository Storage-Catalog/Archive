Simple comparator faders (56-336gt) that give a longer output (when a memory cell fader is not needed). Pulse the repeater(s) to turn them on.
## Features
- Faders (56-336gt)
- 2gt pulse the repeater(s) to turn on
- Can take output (solid-state, monostable, etc.) from anywhere
- No credits because it's so easy
## Instructions
1. 2gt pulse the repeater(s) to turn on.
